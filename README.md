# Rejected Olympic Sports — Synchronized Queue Standing

One funny single-line sport the Olympics turned down: competitive queue standing, given dead-serious Olympic treatment. Four athletes hold their place in a 40-minute airport line, judged on posture and patience — and gold goes to whoever sighs last. The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating that it is a single line of 1–200 characters.
